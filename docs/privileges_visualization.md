# Privilege Configuration Visualization

## Privilege Hierarchy

```mermaid
graph TD
    subgraph Privilege Hierarchy
        admin["admin<br/>全アクセス"]
        dept_head["department_head<br/>部署レベル"]
        sect_mgr["section_manager<br/>課レベル+タブ別スコープ"]
        member["member<br/>課レベル・個人タブなし"]
        anon["anonymous<br/>アクセスなし"]
        admin --> dept_head
        dept_head --> sect_mgr
        sect_mgr --> member
        admin --> anon
    end
    subgraph Department Heads
        sd["sd<br/>システム開発部 + 機電設計部"]
        me["me<br/>システム開発部 + 機電設計部"]
        dev["dev<br/>開発部"]
    end
    dept_head -.-> sd
    dept_head -.-> me
    dept_head -.-> dev
    subgraph Section Managers
        sw["sw<br/>広域:システム開発部 + 機電設計部<br/>個人:ソフトウェア開発課"]
        pd["pd<br/>広域:システム開発部 + 機電設計部<br/>個人:製品技術課"]
        me1["me1<br/>広域:システム開発部 + 機電設計部<br/>個人:第一設計課"]
        me2["me2<br/>広域:システム開発部 + 機電設計部<br/>個人:第二設計課"]
        me3["me3<br/>広域:システム開発部 + 機電設計部<br/>個人:第三設計課"]
        dev1["dev1<br/>広域:開発部<br/>個人:開発部 1課 + UTI技術発展処"]
        dev2["dev2<br/>広域:開発部<br/>個人:開発部 2課 + UK S1-Project"]
        uti["uti<br/>広域:開発部<br/>個人:開発部 1課 + UTI技術発展処"]
        uks1["uks1<br/>広域:開発部<br/>個人:開発部 2課 + UK S1-Project"]
    end
    sect_mgr -.-> sw
    sect_mgr -.-> pd
    sect_mgr -.-> me1
    sect_mgr -.-> me2
    sect_mgr -.-> me3
    sect_mgr -.-> dev1
    sect_mgr -.-> dev2
    sect_mgr -.-> uti
    sect_mgr -.-> uks1
    subgraph Members
        soft["soft<br/>システム開発部 + 機電設計部"]
        prod["prod<br/>システム開発部 + 機電設計部"]
        design1["design1<br/>システム開発部 + 機電設計部"]
        design2["design2<br/>システム開発部 + 機電設計部"]
        design3["design3<br/>システム開発部 + 機電設計部"]
    end
    member -.-> soft
    member -.-> prod
    member -.-> design1
    member -.-> design2
    member -.-> design3
```
