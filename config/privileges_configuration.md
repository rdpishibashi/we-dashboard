# Privilege Configuration

## Privilege Classes

Maps each privilege to its base class. Valid class types: `admin`, `anonymous`, `department_head`, `section_manager`, `member`, `member_no_grade_filter`.

| anonymous | anonymous |
| sd | department_head |

## Feature Configuration

### 幹部職に伝えたいこと
response_enabled = true: 表示あり（管理職は名前表示＋レスポンス可、member クラスは匿名表示のみ）
response_enabled = false: member/member_no_grade_filter クラスはセクション非表示、その他は名前表示のみ（レスポンス UI なし）
